# Gate: ビルドと検証

## 目的

各変更を実行可能な試験で検証し、OSごとの確認範囲を記録する。

## 判定条件

- [ ] 該当単位のCargoビルド、テスト、フォーマットとClippyの結果を確認した。
- [ ] 合成データだけで通常テストを実行できる。実機とCIの結果は環境ごとに記録する。
- [ ] 配布用変更では各OSのアーカイブから展開した本体の `--smoke-test` が主・投影画面の描画を検証した（UbuntuはWaylandとX11の両方）。展開したLua・メディアを起動できる。
- [ ] 配布用ソースアーカイブを新規ディレクトリへ展開し、空の `CARGO_HOME` と新しいビルド先で固定版の `cargo build --workspace --frozen` が完走した。
- [ ] 再生用Rustコードまたは生成ツールに変更があるとき、同梱するJS・Wasmが固定ツールチェーンによる再生成結果とバイト単位で一致する。

## 不合格条件

- [ ] 未実行の試験を成功として報告している。

## 判定

YES / NO
