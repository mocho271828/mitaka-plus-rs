## 検証環境

- macOSの開発機では利用者の実データで数値比較、GPU描画、画像出力、Lua、媒体の操作を実行しました。天文データと画像は配布物・CIに含みません。
- macOS、Windows Server 2025 x64、Ubuntu 24.04 x64のCIでビルド・テスト・Clippy・描画を検査します。UbuntuはWayland（Weston）とX11（Xvfb）を別々に起動します。配布ZIPとdebは展開した実行ファイルから合成星表を読み込みます。
- Windows 11実機、Intel Mac実機、複数の物理モニター、OSごとのフォントやGPUの全画素一致、各コーデックと実音声装置の組み合わせは未検証です。macOS配布物ではApple Silicon・Intelの両アーキテクチャをビルドします。

算出値は元のファイルと計算モデルを引き継ぎます。暦表の範囲、正の年周視差、取得できる軌道期間などの制約も元データに依存します。描画・数値を照合した箇所、非対応項目は上の表と個別のテストで確認できます。
